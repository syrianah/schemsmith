# Generated block registries

Files here are **derived data** generated by `scripts/gen_registry.py` from Mojang's data generator (`--reports`). They are committed under OQ-4's default; the server jar never is.

| File | Content |
|---|---|
| `<mc-version>.json` | every block of that version: properties with allowed values, default state, data version |
| `history.json` | for each block, the first release (among the versions the script ran for) that has it |

Regenerate (needs network access to `piston-meta.mojang.com` / `piston-data.mojang.com` and Java 21+):

```bash
uv run python scripts/gen_registry.py 1.21.11 26.3
uv run python scripts/gen_registry.py --history 1.13 1.14 1.15 1.16 1.17 1.18 1.19 1.20 1.20.5 1.21 1.21.11 26.3
```

Supported versions follow OQ-2's default (`DEFAULT_MC_VERSIONS` in `schemsmith/registry/__init__.py`).
