# Test registry data

Hand-written, tiny stand-ins for generated registries (not derived from Mojang files):

- `mini-1.21.11.json`: the blocks used by the timer fixtures plus `glass`, with their real property values.
- `history.json`: a hand-written history in which `waxed_copper_bulb` first appears in 1.21 (data version 3953, the release that added copper bulbs) and every other block in 1.18.2 (2975).
